# Лабораторная работа 10

Наблюдатель, Состояние. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки выполните `python app.py`. Нужен Python 3.9+ с Tkinter.

## Проверка работы

Вычислите сумму: два уведомления означают начало и завершение операции. Введите x вместо A и нажмите «Вычислить»: появится ошибка и ещё два уведомления. Исправьте A и повторите вычисление: программа вернётся в состояние «Готов». Вычисление выполняется в потоке интерфейса.

Для исходных матриц A = [[1, 2], [3, 4]] и B = [[5, 6], [7, 8]]:
сумма – [[6, 8], [10, 12]], разность – [[-4, -4], [-4, -4]],
произведение – [[19, 22], [43, 50]].
