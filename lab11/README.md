# Лабораторная работа 11

Стратегия, Шаблонный метод. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки выполните `python app.py`. Нужен Python 3.9+ с Tkinter.

## Проверка работы

Выберите A × B и алгоритм «Обычный», выполните вычисление. Выберите «С транспонированием B» и повторите. Результаты совпадают; при смене алгоритма кэш очищается. Обе стратегии поддерживают прямоугольные матрицы при совместимых размерах.

Для исходных матриц A = [[1, 2], [3, 4]] и B = [[5, 6], [7, 8]]:
сумма – [[6, 8], [10, 12]], разность – [[-4, -4], [-4, -4]],
произведение – [[19, 22], [43, 50]].

## Файлы

- Диаграммы – папка «Диаграммы» (PNG и SVG).
- Примеры входных файлов – папка «Примеры».
- Автоматические проверки: `python -m unittest discover -v`.
