# Лабораторная работа 11

Стратегия и Шаблонный метод. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки: `python app.py`. Нужен Python 3.9+ с Tkinter.
Проверки: `python -m unittest discover -v`.

## Основные файлы

algorithms.py: классы стратегий и общий шаблон операции.

## Показ программы

Выберите A × B и алгоритм «Обычный», вычислите результат. Затем выберите «С транспонированием B» и вычислите снова. Оба раза получится [[19, 22], [43, 50]]. При переключении кэш очищается. На диаграммах покажите ссылку strategy и общий сценарий execute().
