# Лабораторная работа 8

Цепочка обязанностей. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки выполните `python app.py`. Нужен Python 3.9+ с Tkinter.

## Проверка работы

Вычислите A + B. Затем замените B на строку `5 6 7` и повторите вычисление: появится ошибка размеров, предыдущий результат сохранится.

Для исходных матриц A = [[1, 2], [3, 4]] и B = [[5, 6], [7, 8]]:
сумма – [[6, 8], [10, 12]], разность – [[-4, -4], [-4, -4]],
произведение – [[19, 22], [43, 50]].
