# Лабораторная работа 15

Пул потоков и Future. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки: `python app.py`. Нужен Python 3.9+ с Tkinter.
Проверки: `python -m unittest discover -v`.

## Основные файлы

background.py: пул и Future; presenter.py: запуск и опрос результата; view.py: доступность элементов.

## Показ программы

Вычислите сумму: появится сообщение «Результат Future получен». Для более заметного процесса можно использовать умножение матриц 100 × 100. На время расчёта поля отключаются и работает индикатор. На малых матрицах вычисление заканчивается быстро. Рабочий поток не обращается к виджетам; after() проверяет готовность в основном потоке.
