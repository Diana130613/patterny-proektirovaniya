# Паттерны проектирования

Матричный калькулятор, вариант 6. Python 3 и Tkinter, без сторонних библиотек.

| Папка | Паттерны |
| --- | --- |
| `lab01` | Одиночка |
| `lab02` | Фабричный метод, Прототип |
| `lab03` | Адаптер, Мост |

Из нужной папки:

```sh
python app.py
python -m unittest -v
```

Диаграммы находятся в папках `diagrams`. В TXT сначала задаются число строк и столбцов, затем элементы. В CSV для `lab03` используются разделитель `;` и строки без заголовка размеров.
