## Что умеет калькулятор

- Сложение и вычитание матриц A и B.
- Умножение матрицы A на число и на матрицу B.
- Ввод матриц с клавиатуры и загрузка из TXT-файла.
- Сохранение результата в TXT-файл.
- Показ портрета матрицы: цвет клетки обозначает знак элемента.
- Изменение настроек и их сохранение между запусками.

Для сложения и вычитания размеры матриц должны совпадать. Для умножения число столбцов A должно равняться числу строк B. Максимальный размер матрицы — 100 × 100. При неправильном вводе программа показывает сообщение об ошибке.

## Запуск

Нужен Python 3.9 или новее с Tkinter. Сторонние библиотеки устанавливать не требуется. В Windows Tkinter обычно входит в установку Python.

Откройте терминал в папке репозитория и перейдите в нужную лабораторную. Например, для первой:

```sh
cd lab01
python app.py
```

Для другой работы вместо `lab01` укажите её папку, например `lab07`. В Windows, если команда `python` недоступна, можно использовать `py`.

## Как пользоваться

1. Введите A и B: элементы разделяйте пробелами, каждую строку матрицы начинайте с новой строки. Размеры в полях ввода указывать не нужно.
2. Выберите операцию. Для «A × число» заполните поле «Число».
3. Нажмите «Вычислить». Появятся результат и его цветной портрет.
4. Чтобы посмотреть портрет исходной матрицы, выберите A или B и нажмите «Показать».
5. Кнопки «Загрузить из файла» и «Сохранить результат в файл» позволяют работать с TXT-файлами.

Дробные числа можно вводить с точкой или запятой. По умолчанию положительные элементы показаны зелёным, отрицательные — красным, нули — белым.

В «Настройках» можно изменить точность отображения, размер шрифта, размер клетки, показ сетки и три цвета. Всего 7 параметров. После сохранения они записываются в `settings.json` рядом с программой и загружаются при следующем запуске. Округление влияет только на показ результата, в файл записывается полная точность `float`.

## Лабораторная работа 1 — Одиночка

**Цель:** сделать матричный калькулятор и использовать паттерн «Одиночка» для общих настроек.

Класс [`AppSettings`](lab01/settings.py) хранит настройки приложения. В методе `__new__` объект создаётся только при первом обращении. Все следующие вызовы возвращают тот же объект:

```python
from settings import AppSettings

a = AppSettings()
b = AppSettings()
print(a is b)  # True
```

Благодаря этому главное окно, окно настроек и рисование портрета используют одни и те же значения. Например, после изменения цвета в настройках портрет перерисовывается с новым цветом.

Основные файлы:

- [`app.py`](lab01/app.py) — интерфейс, обработка кнопок и рисование портрета.
- [`matrix.py`](lab01/matrix.py) — класс `Matrix`, операции и работа с файлами.
- [`settings.py`](lab01/settings.py) — Одиночка и сохранение настроек.
- [`test_lab.py`](lab01/test_lab.py) — тесты матриц и настроек.
- [Диаграмма классов](lab01/diagrams/singleton.svg).
- [Отчёт по лабораторной 1](lab01/лаб1.docx).

Для проверки можно выполнить умножение A × B, сохранить результат и загрузить его обратно. Затем изменить цвет или размер клетки и посмотреть, как изменится портрет.

## Лабораторная работа 2 — Фабричный метод и Прототип

**Цель:** дополнить калькулятор двумя порождающими паттернами. Возможности первой работы и общие настройки сохранены.

### Фабричный метод

В файле [`creators.py`](lab02/creators.py) есть общий класс `MatrixCreator`. Его метод `prepare()` вызывает `create_matrix()` и возвращает матрицу вместе со строкой её размеров. Способ создания задаётся в наследниках:

- `TextMatrixCreator` создаёт матрицу из текста, введённого пользователем.
- `FileMatrixCreator` загружает матрицу из файла.

Так общий порядок работы остаётся одним, а создание матрицы зависит от выбранного источника.

### Прототип

В классе [`Matrix`](lab02/matrix.py) добавлен метод `clone()`. Он создаёт отдельную копию матрицы, включая её строки. Изменение копии не меняет исходную матрицу.

В интерфейсе для этого есть две кнопки:

1. «Запомнить A как образец» — сохраняет копию текущей матрицы A.
2. «Копия образца в B» — создаёт копию сохранённого образца и помещает её в поле B.

Для проверки запомните A, затем измените её в поле ввода и скопируйте образец в B. В B должны появиться значения, которые были в A в момент запоминания. Образец хранится в памяти до закрытия программы.

## Лабораторная работа 4 — Компоновщик и Декоратор

**Цель:** вычислять составные матричные выражения и добавлять оформление результата.

В [`expressions.py`](lab04/expressions.py) выражение хранится как дерево. `MatrixValue` возвращает готовую матрицу, `MatrixOperation` вычисляет два дочерних выражения и выполняет операцию. Оба класса реализуют `MatrixExpression.evaluate()`. В списке операций добавлено `(A + B) × A`.

В [`formatters.py`](lab04/formatters.py) `PlainFormatter` выводит элементы матрицы. Декораторы `RowNumbersFormatter` и `SizeFormatter` добавляют номера строк и размер. Флажки «Номера строк» и «Размер матрицы» можно включать по отдельности или вместе. Оформление меняет только текст результата; в TXT сохраняется обычная матрица.

Для проверки введите A = `[[1, 2], [3, 4]]` и B = `[[5, 6], [7, 8]]`. Выражение `(A + B) × A` должно дать `[[30, 44], [46, 68]]`. Включите оба флажка, затем выключите их и сохраните результат в файл.

Дополнительные материалы: [тесты](lab04/test_composite_decorator.py), [диаграмма Компоновщика](lab04/diagrams/composite.svg), [диаграмма Декоратора](lab04/diagrams/decorator.svg).

## Лабораторная работа 5 — Фасад и Приспособленец

**Цель:** упростить вызов операций калькулятора и использовать общие стили клеток портрета.

[`CalculatorFacade`](lab05/facade.py) принимает текст матриц и выбранную операцию, загружает TXT или CSV и сохраняет результат. Окно обращается к фасаду, а тот связывает разбор данных, вычисления и работу с файлами.

В [`cell_styles.py`](lab05/cell_styles.py) неизменяемый `CellStyle` хранит цвет и знак. `CellStyleFactory` возвращает один объект для клеток с одинаковым оформлением. Координаты и объект рисования передаются отдельно. Для одной палитры достаточно трёх стилей; количество клеток на холсте не меняется.

Для проверки вычислите A + B, загрузите матрицу из CSV и сохраните результат в TXT. Покажите портрет `[[1, 2, 0], [-1, -2, 0]]`: у него шесть клеток и три общих стиля. Измените цвет в настройках и снова покажите портрет.

Дополнительные материалы: [тесты](lab05/test_facade_flyweight.py), [диаграмма Фасада](lab05/diagrams/facade.svg), [диаграмма Приспособленца](lab05/diagrams/flyweight.svg).

## Лабораторная работа 6 — Заместитель

**Цель:** повторно использовать результаты одинаковых вычислений.

[`CachedCalculator`](lab06/proxy.py) и [`CalculationService`](lab06/calculator.py) реализуют общий интерфейс `MatrixCalculator`. Заместитель проверяет кэш перед вызовом сервиса. Ключ учитывает значения и форму матриц, операцию и множитель. Результаты выдаются в отдельных копиях, ошибки не кэшируются.

Кэш хранит до двадцати запросов. При переполнении удаляется самый давно не использовавшийся. Для проверки дважды вычислите A × B: сначала появится «Результат вычислен», затем «Результат из кэша». Измените элемент A или нажмите «Очистить кэш»: следующий запрос будет вычислен заново.

Дополнительные материалы: [тесты](lab06/test_proxy.py), [диаграмма Заместителя](lab06/diagrams/proxy.svg).

## Лабораторная работа 7 — Команда и Итератор

**Цель:** добавить отмену вычислений и последовательный обход матрицы.

В [`commands.py`](lab07/commands.py) `CalculateCommand` хранит запрос и предыдущий результат. `ResultStore` принимает новый результат, `CommandHistory` выполняет команды и отменяет их по очереди. Неудачный запрос сохраняет предыдущий результат и не добавляется в историю.

В [`iterators.py`](lab07/iterators.py) `MatrixIterator` обходит матрицу по строкам и возвращает `(строка, столбец, значение)` с индексами от нуля. Каждый вызов `iter(matrix)` создаёт независимый обход. Через него `sign_counts()` подсчитывает положительные, отрицательные и нулевые элементы результата.

Для проверки выполните A + B, затем A - B. Кнопка «Отменить» вернёт сумму, повторное нажатие уберёт результат. Отмена меняет результат, исходные поля ввода сохраняются. Для матрицы `[[1, -2, 0], [3, 4, -5]]` подсчёт даёт 3 положительных, 2 отрицательных и 1 нулевой элемент.

Дополнительные материалы: [тесты](lab07/test_command_iterator.py), [диаграмма Команды](lab07/diagrams/command.svg), [диаграмма Итератора](lab07/diagrams/iterator.svg).

## Формат TXT-файла

В первой строке указываются число строк и столбцов, затем элементы матрицы. Например:

```text
2 2
1 2
3 4
```

Файл должен быть в кодировке UTF-8. Количество элементов должно соответствовать указанным размерам. Сохранённый результат можно снова загрузить как A или B.

Начиная с `lab03` также поддерживается CSV: разделитель `;`, без строки с размерами.

## Проверка

Из папки соответствующей лабораторной выполните:

```sh
python -m unittest -v
```

В первой работе проверяются арифметические операции, ошибки ввода, чтение и запись файлов, единственный объект настроек и сохранение параметров. Во второй добавлены проверки создания матриц через фабричный метод и независимости копий.

Пример для ручной проверки: A = `[[1, 2], [3, 4]]`, B = `[[5, 6], [7, 8]]`.

| Операция | Результат |
| --- | --- |
| A + B | `[[6, 8], [10, 12]]` |
| A - B | `[[-4, -4], [-4, -4]]` |
| A × 2 | `[[2, 4], [6, 8]]` |
| A × B | `[[19, 22], [43, 50]]` |

В работах 5, 6 и 7 выполняются соответственно 43, 50 и 58 тестов, включая проверки предыдущих паттернов.
