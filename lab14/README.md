# Лабораторная работа 14

Repository. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки: `python app.py`. Нужен Python 3.9+ с Tkinter.
Проверки: `python -m unittest discover -v`.

## Основные файлы

repository.py: общий интерфейс и SQLite; presenter.py: действия сохранения, загрузки и удаления.

## Показ программы

Вычислите сумму, введите название и нажмите «В базу». Измените A, выполните другое вычисление, выберите запись и нажмите «Загрузить». Восстановятся поля и результат. Записи доступны после повторного запуска. «Удалить» удаляет выбранную запись из базы, не изменяя текущий результат и журнал событий.
