# Лабораторная работа 12

MVP. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки: `python app.py`. Нужен Python 3.9+ с Tkinter.
Проверки: `python -m unittest discover -v`.

## Основные файлы

model.py, view.py, presenter.py: три части MVP.

## Показ программы

Вычислите A × B, затем A − B и нажмите «Отменить». Вернётся произведение. В app.py покажите создание модели, представления и презентера. В model.py нет виджетов, в presenter.py действия обрабатываются через методы представления. Отдельные тесты презентера работают без окна.
