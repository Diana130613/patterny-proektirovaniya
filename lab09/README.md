# Лабораторная работа 9

Посредник, Снимок. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки выполните `python app.py`. Нужен Python 3.9+ с Tkinter.

## Проверка работы

Вычислите сумму и нажмите «Сохранить сеанс». Измените A и операцию, выполните другое вычисление, затем нажмите «Восстановить сеанс». Вернутся поля и сохранённый результат. Поле «Число» доступно только для A × число. Снимок один, хранится до закрытия окна; настройки и кэш в него не входят.

Для исходных матриц A = [[1, 2], [3, 4]] и B = [[5, 6], [7, 8]]:
сумма – [[6, 8], [10, 12]], разность – [[-4, -4], [-4, -4]],
произведение – [[19, 22], [43, 50]].
