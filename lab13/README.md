# Лабораторная работа 13

Event Sourcing. Вариант 6 – матричный калькулятор.

## Запуск

Из этой папки: `python app.py`. Нужен Python 3.9+ с Tkinter.
Проверки: `python -m unittest discover -v`.

## Основные файлы

event_store.py: файл событий; projection.py: применение событий; journal_model.py: модель.

## Показ программы

Вычислите сумму, затем разность и нажмите «Отменить». Нажмите «Восстановить из журнала»: останется сумма. В журнале три события. Закройте окно и запустите приложение снова: состояние восстановится из того же файла. Список событий открывается кнопкой «История событий». Отмена меняет только результат, а выбранная операция остаётся последней.
